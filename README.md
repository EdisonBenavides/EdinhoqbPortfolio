# Portfolio — Software Developer

Portfolio personal construido con Astro + TypeScript, con enfoque técnico, accesibilidad, SEO y rendimiento.

## Ejecutar

```bash
npm install
npm run dev
```

## Antes de publicar

1. Reemplazar `public/images/profile-placeholder.svg` por la foto real.
2. Colocar el CV en `public/cv/CV-Software-Developer.pdf`.
3. Cambiar email, GitHub y LinkedIn en `src/pages/index.astro`.
4. Cambiar `site` en `astro.config.mjs` por el dominio real.
5. Añadir URLs reales de demos/repositorios en `src/data/projects.ts`.
6. Revisar y sustituir cualquier dato que quieras actualizar.

## Build

```bash
npm run build
npm run preview
```
